- Optional read-only reviewer credential for the panel hub (header `X-AMB-Reviewer-Token`, file `panel-reviewer.token`, off by default): it can list plans and read proofs and is refused with 403 on approve, reject, approval-mode changes and every other route. A wrong `X-AMB-Token` is refused (401) and counted by the rate limiter even when a valid reviewer header comes with it. A reviewer's `instance` field is ignored, `/diagnostics` runs no write test, and `/diagnostics` and `/reports` omit absolute workspace paths. Fixes #210.
