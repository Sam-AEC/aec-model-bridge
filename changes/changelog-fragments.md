- Changelog fragments: each change adds `changes/<issue-or-branch>.md` instead of editing `CHANGELOG.md`; `scripts/changelog.py check` validates them and `scripts/changelog.py build --version X.Y.Z` folds them (and any `## Unreleased` lines) into the release section. `scripts/sync_counts.py` rewrites every tool count claim (README, translated READMEs, `llms.txt`, token budget header); CI runs both checks and `scripts/make_llms_full.py --check`, so PRs no longer conflict on the changelog, the tool count or `llms-full.txt`.
